# 📝 Инструкция по запуску Modern Notepad

## ⚡ Быстрый старт

### Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Это установит все необходимые пакеты (React, Electron, Monaco Editor и др.)

### Шаг 2: Запуск приложения

После установки зависимостей запустите приложение командой:

```bash
npm run electron-dev
```

Эта команда:
- Запустит React сервер разработки на порту 3000
- Автоматически откроет Electron окно с приложением
- Включит режим разработки с горячей перезагрузкой

### Шаг 3: Использование

1. **Выберите язык** из выпадающего списка в верхней панели
2. **Напишите код** в редакторе слева
3. **Нажмите "Выполнить"** или используйте `Ctrl+Enter` для выполнения
4. **Результат** появится в правой панели

## 🛠️ Дополнительные команды

### Запуск только React (без Electron)
```bash
npm start
```
Откроется в браузере на http://localhost:3000

### Сборка для production
```bash
npm run build
npm run electron
```

### Создание установщика для Windows (с ярлыком на рабочем столе)
```bash
npm run electron-pack-win
```

Эта команда:
- Соберет React приложение
- Создаст установщик `Modern Notepad Setup.exe` в папке `dist`
- Установщик создаст ярлык на рабочем столе и в меню "Пуск"

После выполнения команды:
1. Найдите файл `Modern Notepad Setup.exe` в папке `dist`
2. Запустите установщик
3. Следуйте инструкциям установки
4. После установки на рабочем столе появится ярлык "Modern Notepad"
5. Запускайте приложение двойным кликом по ярлыку!

### Создание установщика (универсальный)
```bash
npm run electron-pack
```

## 📋 Требования

- **Node.js** версии 16 или выше
- **npm** (обычно идет с Node.js)

Проверить версию можно командами:
```bash
node --version
npm --version
```

## ❓ Решение проблем

### Ошибка "npm не найден"
Установите Node.js с официального сайта: https://nodejs.org/

### Ошибка при установке зависимостей
Попробуйте:
```bash
npm cache clean --force
npm install
```

### Порт 3000 занят
Измените порт в файле `.env`:
```
PORT=3001
```

### Electron не открывается
Убедитесь, что React сервер запустился (должен быть доступен http://localhost:3000)

## 📋 Логирование ошибок

Приложение автоматически записывает все ошибки и события в файл логов.

**Расположение файла логов:**
- Windows: `%APPDATA%\Modern Notepad\logs\app.log`
- Или: `C:\Users\[ВашеИмя]\AppData\Roaming\Modern Notepad\logs\app.log`

**Что записывается в лог:**
- Все ошибки приложения
- События запуска и закрытия
- Ошибки загрузки страниц
- Необработанные исключения

**Если возникли проблемы:**
1. Найдите файл `app.log` в указанной папке
2. Откройте его текстовым редактором
3. Скопируйте содержимое для диагностики

🔧 ПРОБЛЕМА:
Антивирус блокирует файл установщика во время сборки.

═══════════════════════════════════════════════════════════════

✅ РЕШЕНИЕ:

1. Нажмите Ctrl+C в терминале, чтобы прервать сборку

2. Удалите заблокированный файл:
   - Откройте папку: dist
   - Удалите файл: Modern Notepad Setup 1.0.0.exe
   - Если не удаляется:
     * Временно отключите антивирус
     * Или добавьте папку dist в исключения антивируса

3. Запустите сборку заново:
   npm run electron-pack-win

═══════════════════════════════════════════════════════════════

💡 АЛЬТЕРНАТИВА:

Если проблема повторяется, можно:
- Изменить имя выходного файла в electron-builder.yml
- Или собрать без установщика: npm run build && electron-builder --dir

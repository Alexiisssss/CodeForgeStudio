# Modern Notepad - Современный блокнот для кода

Красивый и быстрый десктопный редактор кода с возможностью выполнения и компиляции.

## 🚀 Возможности

- ✨ Современный и красивый интерфейс в темной теме
- 🎨 Подсветка синтаксиса для множества языков
- ⚡ Быстрая работа благодаря Monaco Editor (редактор из VS Code)
- ▶️ Выполнение JavaScript кода в реальном времени
- 📱 Адаптивный дизайн
- ⌨️ Горячие клавиши (Ctrl+Enter для выполнения)

## 📋 Требования

- Node.js (версия 16 или выше)
- npm или yarn

## 🔧 Установка и запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Запустите приложение в режиме разработки

```bash
npm run electron-dev
```

Эта команда запустит:
- React приложение на http://localhost:3000
- Electron окно с приложением

### 3. Сборка для production

```bash
npm run build
npm run electron
```

### 4. Создание установщика

```bash
npm run electron-pack
```

## 🎮 Использование

1. Выберите язык программирования в выпадающем списке
2. Напишите код в редакторе
3. Нажмите кнопку "Выполнить" или используйте `Ctrl+Enter`
4. Результат выполнения появится в правой панели

## 🛠️ Поддерживаемые языки

- JavaScript (с полной поддержкой выполнения)
- Python (базовая поддержка)
- TypeScript
- Java
- C++
- C#
- HTML
- CSS

## 📝 Примечания

- JavaScript код выполняется напрямую в браузере
- Для других языков требуется дополнительная настройка компиляторов/интерпретаторов
- Приложение использует Electron для десктопной версии

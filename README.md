# CodeForge Studio - современный блокнот для кода в двух режимах (язык программирования + SQL)

**[English](README.en.md)** | **Русский**

Красивый и быстрый десктопный редактор кода с выполнением, компиляцией, работой с файлами и SQL.

## 🚀 Возможности

- ✨ Современный интерфейс в тёмной теме
- 🎨 Подсветка синтаксиса для множества языков (CodeMirror 6)
- ⚡ Быстрая работа, подсветка текущей строки, нумерация строк, свёртка кода, мини-карта
- ▶️ Выполнение JavaScript в браузере; Python, Java, C++, C#, Go — через Electron
- 📁 **Работа с файлами:** Открыть, Сохранить, Сохранить как (диалоги ОС)
- 📂 **Недавние файлы** — выпадающий список последних открытых/сохранённых файлов
- 📑 **Два окна (split view)** — разделение на левую и правую панель, у каждой свои вкладки и кнопки Открыть/Сохранить
- 🗄️ **Режим SQL** — запросы слева, таблицы и ER-диаграмма справа (SQLite in-memory, PostgreSQL, Oracle)
- 🤖 **AI-ассистент (Ollama)** — чат с локальной моделью прямо в приложении. **Читает контекст:** код из текущей вкладки автоматически подставляется в запрос, можно спрашивать «что не так в коде», «объясни строку» без копирования. Отдельный чат для каждой вкладки, перетаскиваемое окно с изменяемым размером.
- ⌨️ Горячие клавиши (F8, Ctrl+Enter, Ctrl+Alt+L, Ctrl+T и др.)
- 💾 Автосохранение вкладок и кода в localStorage; **«грязные» вкладки** (• в названии и предупреждение при закрытии)

## 📋 Требования

- Node.js (версия 16 или выше)
- npm или yarn

## 🔧 Установка и запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run electron-dev
```

Запускаются React на http://localhost:3000 и окно Electron.

### 3. Сборка для production

```bash
npm run build
npm run electron
```

### 4. Создание установщика

```bash
npm run electron-pack
```

Для Windows:

```bash
npm run electron-pack-win
```

## 🎮 Использование

1. Выберите язык в выпадающем списке.
2. Пишите код в редакторе.
3. Нажмите **«Выполнить»** или `Ctrl+Enter` / `F8` — результат появится в панели вывода.

### Работа с файлами

- **Открыть** — диалог выбора файла, содержимое подставляется в текущую вкладку (в split — в активную вкладку левого окна).
- **Сохранить** — сохраняет в файл текущей вкладки (если путь уже есть) или открывает диалог «Сохранить как».
- **Сохранить как** — всегда запрашивает путь и сохраняет код в выбранный файл.
- **Недавние файлы** — выпадающий список в верхней панели; выбор пункта открывает файл в текущем редакторе.

В режиме **«Два окна»** у правой панели свои кнопки **Открыть / Сохранить / Сохранить как** для активной вкладки правого окна.

### Вкладки и несохранённые изменения

- Если код во вкладке менялся после открытия или последнего сохранения, в названии вкладки отображается **•**.
- При закрытии такой вкладки появляется вопрос: «Сохранить изменения?».

### Режим SQL

- Кнопка **SQL** переключает в режим запросов: слева редактор SQL, справа — список таблиц, просмотр данных таблицы и ER-диаграмма.
- Поддерживаются диалекты: **SQL (in-memory)** (sql.js), **PostgreSQL**, **Oracle** (для последних двух настраивается подключение в панели).

### AI-ассистент (Ollama)

- Кнопка **AI Assistant** рядом с «Очистить» в блоке **Результат выполнения** открывает окно чата с локальной моделью [Ollama](https://ollama.com).
- **Контекст кода:** при каждом вопросе в запрос автоматически подставляется код из **текущей вкладки** (или выделенный фрагмент). Достаточно написать «что не так?» или «объясни эту функцию» — модель видит ваш код.
- У каждой вкладки **свой чат**: переключили вкладку — открывается история чата этой вкладки (пустая или уже начатая).
- В окне чата: выбор модели (llama3.2, gemma3:4b, qwen3:8b и др.), кнопка «Запустить модель» без терминала, при необходимости — скачивание установщика Ollama с отображением прогресса. Окно можно перетаскивать и растягивать за правый нижний угол.

## 📝 Примечания

- JavaScript выполняется в браузере; **Java, Python, C++, C#, Go** — через Electron (главный процесс). В браузере без Electron эти языки не запускаются.
- Для Java / C++ / C# / Go нужны установленные компиляторы и интерпретаторы в PATH (JDK, Python, g++/MSVC, .NET SDK, Go). **Для Java рекомендуется JDK 21** — с ним и запуск кода, и форматирование (google-java-format 1.29+) работают без доп. настроек. Если в системе несколько JDK и запускается не та версия (например, из-за Oracle javapath в PATH), задайте **JAVA_HOME** на нужный JDK или поставьте его `bin` в PATH выше остальных.
- Для **красивого Java‑кода** — форматирование через `google-java-format`: положите в папку `tools/` JAR с [релизов](https://github.com/google/google-java-format/releases) и нажимайте `Ctrl+Alt+L` при выбранном Java. **Версии 1.29+ рассчитаны на JDK 21**; при JDK 24/25 задайте **`JAVA_FORMATTER_HOME`** — путь к JDK 21. При JDK 17 используйте [JAR 1.28](https://github.com/google/google-java-format/releases/tag/v1.28.0).
- Для Java есть отдельное поле стандартного ввода (stdin): каждая введённая туда строка попадает в `Scanner(System.in)` как отдельная строка ввода.
- Редактор построен на **CodeMirror 6** (@uiw/react-codemirror).

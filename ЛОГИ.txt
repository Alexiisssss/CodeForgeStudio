📁 Расположение файла логов:

Windows:
  %APPDATA%\Modern Notepad\logs\app.log

Или полный путь:
  C:\Users\[ВашеИмя]\AppData\Roaming\Modern Notepad\logs\app.log

═══════════════════════════════════════════════════════════════

🔍 Как открыть папку с логами:

1. Нажмите Win + R
2. Введите: %APPDATA%\Modern Notepad\logs
3. Нажмите Enter
4. Откройте файл app.log

═══════════════════════════════════════════════════════════════

📝 Что записывается в лог:

✓ Все ошибки приложения
✓ События запуска и закрытия
✓ Ошибки загрузки страниц
✓ Необработанные исключения
✓ Информация о версии и путях

═══════════════════════════════════════════════════════════════

💡 Если возникли проблемы:

1. Найдите файл app.log
2. Откройте его в Блокноте
3. Скопируйте содержимое для диагностики
4. Файл обновляется автоматически при каждом запуске

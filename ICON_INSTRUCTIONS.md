# Инструкция по созданию иконки приложения

## Требования к иконке

Для Windows приложения нужен файл `.ico` с размерами:
- 16x16 пикселей
- 32x32 пикселей  
- 48x48 пикселей
- 256x256 пикселей (рекомендуется)

## Способы создания иконки

### Способ 0: Использование готовой SVG иконки (уже создана)
В корне проекта уже есть файл `icon.svg` с простой иконкой приложения.
1. Откройте `icon.svg` в браузере или графическом редакторе
2. Экспортируйте как PNG 256x256 пикселей
3. Используйте онлайн-конвертер для создания ICO (см. Способ 1)

### Способ 1: Онлайн-конвертер
1. Создайте изображение 256x256 пикселей в любом графическом редакторе (Paint, Photoshop, GIMP и т.д.)
2. Сохраните как PNG
3. Используйте онлайн-конвертер:
   - https://convertio.co/ru/png-ico/
   - https://www.icoconverter.com/
   - https://favicon.io/favicon-converter/
4. Скачайте файл `icon.ico`
5. Поместите его в корень проекта (рядом с `package.json`)

### Способ 2: Использование готовой иконки
1. Найдите готовую иконку в формате ICO
2. Переименуйте её в `icon.ico`
3. Поместите в корень проекта

### Способ 3: Создание через ImageMagick (если установлен)
```bash
# Создать иконку из PNG
magick convert icon.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico
```

## Размещение файла

После создания `icon.ico`:
1. Поместите файл в корень проекта: `C:\Users\Alex\Desktop\блокнот\icon.ico`
2. Пересоберите приложение:
   ```bash
   npm run build
   npm run electron-pack-win
   ```

## Проверка

После пересборки иконка будет использоваться:
- В установщике
- В ярлыке на рабочем столе
- В окне приложения (в заголовке)
- В меню "Пуск"

    КАК УСТАНОВИТЬ PYTHON НА WINDOWS
═══════════════════════════════════════════════════════════════

📦 ШАГ 1: НАЙДИТЕ СКАЧАННЫЙ ФАЙЛ

Обычно файл называется:
- python-3.x.x-amd64.exe (для 64-битной Windows)
- python-3.x.x.exe (для 32-битной Windows)

Найдите его в папке "Загрузки" (Downloads)

═══════════════════════════════════════════════════════════════

🔧 ШАГ 2: ЗАПУСТИТЕ УСТАНОВЩИК

1. Дважды кликните на файл python-3.x.x-amd64.exe
2. Появится окно установки

═══════════════════════════════════════════════════════════════

✅ ШАГ 3: ВАЖНО! ОТМЕТЬТЕ "Add Python to PATH"

В окне установки:
1. Внизу будет галочка "Add Python to PATH"
2. ✅ ОБЯЗАТЕЛЬНО отметьте эту галочку!
3. Это нужно, чтобы Python работал из командной строки

═══════════════════════════════════════════════════════════════

▶️ ШАГ 4: НАЖМИТЕ "Install Now"

1. Нажмите кнопку "Install Now"
2. Дождитесь завершения установки
3. Может потребоваться разрешение администратора - нажмите "Да"

═══════════════════════════════════════════════════════════════

✅ ШАГ 5: ПРОВЕРЬТЕ УСТАНОВКУ

1. Нажмите Win+R
2. Введите: cmd
3. Нажмите Enter
4. В командной строке введите: python --version
5. Должно показать: Python 3.x.x

Если показывает версию - всё готово! ✅

═══════════════════════════════════════════════════════════════

⚠️ ЕСЛИ КОМАНДА НЕ РАБОТАЕТ:

Если команда "python --version" не работает:

1. Перезагрузите компьютер
2. Или добавьте Python в PATH вручную:
   - Win+Pause → Дополнительные параметры системы
   - Переменные среды → Path → Изменить
   - Добавьте: C:\Users\ВашеИмя\AppData\Local\Programs\Python\Python3x
   - И: C:\Users\ВашеИмя\AppData\Local\Programs\Python\Python3x\Scripts

═══════════════════════════════════════════════════════════════

🎉 ГОТОВО!

После установки Python будет работать в приложении Modern Notepad!

Перезапустите приложение, чтобы изменения вступили в силу.

📦 ШАГ 1: Установите зависимости
   Выполните в терминале:
   
   npm install

▶️ ШАГ 2: Запустите приложение (режим разработки)
   Выполните в терминале:
   
   npm run electron-dev

✨ Готово! Приложение откроется автоматически.

═══════════════════════════════════════════════════════════════

🖥️ СОЗДАНИЕ УСТАНОВЩИКА (для запуска с рабочего стола):

📦 ШАГ 1: Создайте установщик
   Выполните в терминале:
   
   npm run electron-pack-win

📁 ШАГ 2: Найдите установщик
   Откройте папку dist/
   Там будет файл: Modern Notepad Setup.exe

🚀 ШАГ 3: Установите приложение
   - Запустите Modern Notepad Setup.exe
   - Следуйте инструкциям установки
   - На рабочем столе появится ярлык!

✨ ШАГ 4: Запускайте с рабочего стола
   Двойной клик по ярлыку "Modern Notepad"

═══════════════════════════════════════════════════════════════

💡 ПОДСКАЗКИ:
   - Используйте Ctrl+Enter для выполнения кода
   - JavaScript выполняется сразу
   - Результат появится справа

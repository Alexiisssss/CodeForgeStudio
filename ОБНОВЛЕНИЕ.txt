💡 ТРЕБОВАНИЯ ДЛЯ КОМПИЛЯТОРОВ:

Для работы компиляторов нужно установить:

- Python: https://www.python.org/downloads/
- Java (JDK): https://www.oracle.com/java/technologies/downloads/
- C++ (g++ или clang): 
  * Windows: MinGW или Visual Studio
  * Linux: sudo apt-get install g++
  * macOS: xcode-select --install
- C# (.NET SDK): https://dotnet.microsoft.com/download
- Go: https://go.dev/dl/

После установки убедитесь, что компиляторы доступны в PATH.

📦 ЧТО НУЖНО УСТАНОВИТЬ:

Для работы компиляторов нужно установить их на ваш компьютер.
Это стандартные программы, которые устанавливаются как обычные приложения.

═══════════════════════════════════════════════════════════════

1️⃣ PYTHON
   Скачать: https://www.python.org/downloads/
   Установка:
   - Скачайте установщик для Windows
   - Запустите установщик
   - ✅ ВАЖНО: Отметьте "Add Python to PATH" при установке!
   - Установите в любую папку (по умолчанию C:\Python3x)

2️⃣ JAVA (JDK)
   Скачать: https://www.oracle.com/java/technologies/downloads/
   Установка:
   - Скачайте JDK для Windows
   - Запустите установщик
   - Установите в любую папку (по умолчанию C:\Program Files\Java)
   - ✅ ВАЖНО: JDK автоматически добавится в PATH

3️⃣ C++ (MinGW)
   Скачать: https://www.mingw-w64.org/downloads/
   Или используйте: https://sourceforge.net/projects/mingw-w64/
   Установка:
   - Скачайте MinGW-w64
   - Установите в C:\MinGW (или другую папку)
   - ✅ ВАЖНО: Добавьте C:\MinGW\bin в PATH вручную

4️⃣ C# (.NET SDK)
   Скачать: https://dotnet.microsoft.com/download
   Установка:
   - Скачайте .NET SDK для Windows
   - Запустите установщик
   - Установите в любую папку
   - ✅ ВАЖНО: .NET автоматически добавится в PATH

5️⃣ GO
   Скачать: https://go.dev/dl/
   Установка:
   - Скачайте установщик для Windows
   - Запустите установщик
   - Установите в любую папку (по умолчанию C:\Program Files\Go)
   - ✅ ВАЖНО: Go автоматически добавится в PATH

═══════════════════════════════════════════════════════════════

🔧 КАК ПРОВЕРИТЬ, ЧТО КОМПИЛЯТОРЫ УСТАНОВЛЕНЫ:

Откройте командную строку (Win+R, введите "cmd", нажмите Enter)
и выполните команды:

python --version    (должно показать версию Python)
javac -version      (должно показать версию Java)
g++ --version       (должно показать версию g++)
dotnet --version    (должно показать версию .NET)
go version          (должно показать версию Go)

Если команды не работают, значит компилятор не в PATH.

═══════════════════════════════════════════════════════════════

📝 КАК ДОБАВИТЬ В PATH (если нужно):

1. Нажмите Win+Pause (или ПКМ на "Этот компьютер" → Свойства)
2. Нажмите "Дополнительные параметры системы"
3. Нажмите "Переменные среды"
4. В "Системные переменные" найдите "Path"
5. Нажмите "Изменить"
6. Нажмите "Создать" и добавьте путь к bin папке компилятора
   Например: C:\MinGW\bin
7. Нажмите "ОК" везде
8. Перезапустите приложение

═══════════════════════════════════════════════════════════════

💡 ВАЖНО:

- JavaScript работает БЕЗ установки (встроен в браузер)
- TypeScript работает через JavaScript (без установки)
- HTML/CSS работают БЕЗ установки (просмотр)

Для остальных языков нужны компиляторы.
